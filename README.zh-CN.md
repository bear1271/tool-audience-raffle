# 离线抽奖程序：新手使用说明

[English instructions](README.md)

这份说明适用于通用分享版 Audience Raffle。你不需要安装软件、编程或连接网络。

## 一、第一次打开

1. 将 `Audience-Raffle.zip` 解压到一个固定文件夹，不要直接在压缩包里打开程序。
2. 保留文件夹里的所有文件，不要只复制 `index.html`；它还需要 `app.js` 和 `style.css`。
3. 双击 `index.html`，使用 Chrome 或 Microsoft Edge 打开。如果打开成文本，右键选择“打开方式”，再选择浏览器。
4. 页面上的按钮都是英文。点击 **Admin panel**（后台管理），开始配置。

程序在你的电脑和浏览器里运行，不会自动读取 Luma、问卷或报名表。需要先从这些平台导出名单，再导入程序。

## 二、准备名单：推荐用 CSV

你可以用 Excel 新建表格，第一行写列名：

| Email | Name |
| --- | --- |
| alice@example.com | Alice Chen |
| bob@example.com | 李明 |

上面的邮箱是虚构示例，请换成真实参与者的邮箱。姓名可以是中文或英文。

保存时选择 **CSV UTF-8（逗号分隔）**，文件扩展名应为 `.csv`。不能直接导入 `.xlsx` Excel 工作簿。CSV 第一行必须是列名；每行一个参与者，不要加入标题、说明或合并单元格。

用文本查看，文件应该类似：

```csv
Email,Name
alice@example.com,Alice Chen
bob@example.com,李明
```

程序包里的 `sample-participants.csv` 就是格式示例。请不要把示例里的虚构参与者留在正式名单中。

### 能自动识别哪些列？

程序根据列名识别信息，列顺序可以不同，其他无关列会被忽略。列名不区分英文大小写。

| 内容 | 可识别列名 |
| --- | --- |
| 邮箱 | `Email`、`Email Address`、`E-mail`、`Guest Email`、`Attendee Email` |
| 姓名 | `Name`、`Full Name`、`Guest Name`、`Attendee Name` |
| 分开的名与姓 | `First Name` 和 `Last Name`，也支持 `Firstname` 和 `Lastname` |

最简单、最可靠的做法是统一使用 `Email` 和 `Name`。中文列名“姓名”“邮箱”目前不会自动识别，请先改成英文列名。

邮箱是必填信息；姓名可以不填，没有姓名时会在中奖画面显示邮箱。程序不会根据邮箱去查询真实姓名，也不会猜测任意列的含义。如果存在 `Name` 列，程序优先使用它，不再拼接 First Name / Last Name。

邮箱缺失或格式不正确时，整个导入会停止，不会只导入其中一部分。根据提示修正名单后，再次导入。邮箱检查仅检查基本格式，不能确认这个邮箱真实存在或属于本人。

## 三、也可以用 TXT 或直接粘贴

打开记事本，每行填一个人，使用 `邮箱 | 姓名` 格式。邮箱放前面，中间是英文竖线 `|`，不是逗号。

```text
alice@example.com | Alice Chen
bob@example.com | 李明
```

也可以每行只写邮箱：

```text
alice@example.com
bob@example.com
```

TXT 不写列名，建议保存为 UTF-8，扩展名为 `.txt`。只有姓名、没有邮箱的名单不支持。也可以把这些内容直接粘贴到程序对应的名单框中。

## 四、把名单导入程序

1. 点击 **Admin panel**。
2. 在 **Event name** 填写你的活动名称。
3. 在 **Import into**（导入目标）中选择名单来源：
   - **Registration**：报名名单。
   - **Raffle entry**：现场抽奖登记名单。
   - **Survey**：问卷名单。
4. 点击 **Import CSV / TXT**，选择对应文件。
5. 有多个来源时，分别选择目标、导入对应文件；三个来源会合并成同一个奖池。
6. 点击 **Save pool**（保存奖池），修改才正式生效。
7. 展开 **Review shared raffle pool**，核对姓名、邮箱和人数。

只有一份名单时，全部导入 **Registration** 即可，其余入口留空。

**每次导入会替换所选入口当前的草稿名单，不会追加。**其他入口不受影响。若同一入口有多份文件，请先在 Excel 中合成一份再导入。保存后的人数可能少于表格行数，因为重复邮箱会被合并。

同一邮箱不区分大小写，会视为同一个人。跨入口出现也只占一个名额；不同邮箱会被视为不同人，即使姓名相同。请避免同一个人用多个邮箱参加。

## 五、设置奖项与概率

打开 **Draw settings**（抽奖设置）：

| 设置 | 含义 |
| --- | --- |
| First prize quantity | 一等奖总数量 |
| Second prize quantity | 二等奖总数量 |
| Third prize quantity | 三等奖总数量 |
| Survey weight | 问卷入口的抽奖权重 |
| Multiple entry sources | 同一人在多个来源中出现时，如何计算权重 |

通用分享版默认每个奖项 1 份。奖项数量填写 `0`，表示不抽这个奖项。数量可填 0–10000，每次最多抽 100 人。

如果希望所有人机会相同：将 **Survey weight** 保持为 `1`，并将 **Multiple entry sources** 保持为 **Use highest weight**（取最高权重）。报名和现场登记的权重固定为 1。

如果活动给完成问卷的人额外机会，可将 Survey weight 改为更高的整数。例如 `3` 表示每次抽取一名中奖者时，该参与者的机会为普通参与者的 3 倍。抽取多人时，最终至少中一次的概率不一定是 3 倍。

**Add source weights** 表示叠加不同入口的权重；它会让参加多个入口的人机会更高。普通等概率抽奖不建议选择这个选项。

设置完成后点击 **Save pool**。权重只在后台设置和导出的记录中保留，不会显示在观众画面上。

## 六、正式抽奖

1. 提前确定奖项顺序。默认 **One prize per person across all tiers**（每人只能中一次）已勾选，先中奖的人不能再抽后面的奖项。
2. 关闭报名后，导入最终名单并保存；正式抽奖期间不要随意改名单或规则。
3. 点击 **Close admin panel** 关闭后台，或点击 **Full screen** 全屏投影。全屏会自动关闭后台，按 Esc 可退出。
4. 在页面选择奖项，再填写 **Winners**（本轮抽取人数）。程序会按所选奖项剩余数量填入人数，可改为更小的批次。
5. 点击 **Draw winners**。程序先保存结果，再揭晓中奖名单。
6. 核实中奖者是否在场，在后台历史中点击 **Mark collected** 标记已领奖；也可在 Event notes 中记录备注。

程序不会自动判断是否在场，也没有自动替补功能。缺席、领奖和重抽办法应在活动前明确，不要因为不满意结果就反复重置重抽。

## 七、历史、备份与重置

| 按钮 | 用途 |
| --- | --- |
| Export CSV | 导出中奖名单、领奖状态等，方便用 Excel 查看 |
| Export backup | 导出完整 JSON 备份，包括名单、设置和历史 |
| Restore backup | 用备份替换当前数据，不是合并记录 |
| Reset draw | 删除所有中奖结果、领奖状态、备注和历史；保留活动名称、名单和已保存设置；所有人恢复可抽资格，各奖项恢复原定数量 |
| Reset event | 清空整个活动，恢复默认设置：各奖项 1 份，Survey weight 为 1 |

两种 Reset 都会弹出确认。确认后无法撤销，除非此前导出了备份。

第一次使用时，请用几位虚构参与者试抽。熟悉操作后，用 **Reset event** 清空测试数据，再导入正式名单。

## 八、活动前后提醒

- 使用固定电脑、固定浏览器、固定文件位置。不要使用无痕模式。
- 数据保存在当前浏览器中，不会自动同步到手机、另一台电脑或另一个浏览器。
- 清理浏览器数据可能删除记录。活动前后都建议导出备份。
- 活动前检查姓名显示、人数、奖项数量和投影效果。
- 后台没有密码；操作者可以修改名单和设置，历史记录也不是防篡改凭证。正式抽奖时应固定规则，必要时安排其他工作人员核对。
- 转发程序时发原始 ZIP 即可。不要随包发送真实名单或活动备份；它们包含参与者邮箱。

## 九、常见问题

**导入提示找不到 Email 列？** 先检查 CSV 第一行是不是列名，将邮箱列改为 `Email`。

**Excel 文件选不了？** 先另存为 CSV UTF-8，不是把扩展名 `.xlsx` 直接改成 `.csv`。

**导入后抽不了？** 点击 Save pool；检查可抽人数、奖项剩余数量以及本轮人数。

**中文姓名乱码？** 使用 UTF-8 编码重新保存 CSV/TXT 后导入。

**界面没有后台设置？** 点击页面顶部 Admin panel；全屏状态下先按 Esc。

**刷新后记录不见了？** 确认使用原来的电脑、浏览器和文件位置，并检查是否无痕模式。已有 JSON 备份时可通过 Restore backup 恢复。
