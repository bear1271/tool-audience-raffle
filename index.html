How to import participants

1. Export each source as CSV.
2. Keep Email and Name columns (First Name + Last Name also work).
3. Select the source under Import into.
4. Click Import CSV / TXT. This replaces that source’s draft list.
5. Repeat for other sources, then click Save pool.
6. Review the shared pool before drawing.
